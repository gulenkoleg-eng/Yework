# YEWORK — Є робота!

Платформа пошуку роботи, швидкого підробітку та професійних послуг. Старт: Миронівська, Богуславська та Кагарлицька громади.

**Встановлення на сервер:** [docs/INSTALL.md](docs/INSTALL.md)

## Стан

| Етап | Що є |
|---|---|
| 1. Архітектура | Модулі, схема БД, система прав (RBAC), механізм тем, план |
| 2. Інсталятор і ядро | Веб-інсталятор, міграції, ролі й права, 6 тем, довідник громад, вхід адміністратора, журнал аудиту |

## Структура

```
apps/api            NestJS: інсталятор, вхід, (далі модулі)
apps/web            Next.js: сайт, /install, /admin
packages/db         Drizzle: схема, SQL-міграції, стартові дані
packages/permissions  Довідник прав і системних ролей
infra/Caddyfile     HTTPS і маршрутизація
docker-compose.yml  PostgreSQL 16, Redis 7, api, web, Caddy
```

## Розробка

```bash
corepack enable && pnpm install
pnpm build
pnpm test          # потрібен PostgreSQL для e2e тестів інсталятора
pnpm dev:api & pnpm dev:web
```

## Безпека, закладена з першого дня

- Паролі: Argon2id. Телефони й email: шифрування AES-256-GCM.
- Інсталятор: одноразовий ключ, обмеження спроб, блокування після встановлення.
- Сесії: httpOnly cookie, захист від CSRF, обмеження спроб входу.
- Журнал аудиту не можна змінити чи видалити навіть через SQL.
- Лише один власник платформи (обмеження на рівні бази даних).
