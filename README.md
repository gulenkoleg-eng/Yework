# YEWORK — Є робота!

Платформа пошуку роботи, підробітку та послуг для Миронівської, Богуславської та Кагарлицької громад.

**Технології:** PHP 8.2–8.5 і MySQL 8 / MariaDB 10.6+, без сторонніх бібліотек. Для фото в резюме потрібне розширення GD (є майже на всіх хостингах). Працює на звичайному хостингу.

**Встановлення:** [docs/INSTALL.md](docs/INSTALL.md)

## Що вже працює

- **Веб-інсталятор із 6 кроків.** Ключ встановлення, перевірка сервера, база даних з префіксом таблиць, назва файлу конфігурації, тема, головний адміністратор. Після встановлення інсталятор блокується.
- **Реєстрація за телефоном або email** з кодом підтвердження, вхід за телефоном, email чи логіном, відновлення пароля.
- **Вакансії.** Пошук і фільтри (громада, категорія, зайнятість, зарплата, «без досвіду»), сторінка вакансії, відгук в один клік.
- **Профіль і резюме шукача.** Фото з галочкою «показувати фото», приховування контактів, резюме у PDF, відгук із резюме (PDF роботодавцю на пошту), пошук резюме для роботодавців, запрошення, модерація.
- **Послуги майстрів.** Каталог з категоріями й пошуком, профіль майстра (ФОП/ТОВ, способи оплати), прайс «від – до» з обладнанням, портфоліо об’єктів із фото, термін показу 1–12 місяців з архівом, замовлення через сайт і зірки лише від клієнтів із виконаним замовленням.
- **Кабінет.** Профіль роботодавця, створення й редагування вакансій, чернетки, відгуки з контактами кандидатів, зміна пароля.
- **Логотипи й банери.** Логотип і форма власності роботодавця, банерна реклама з модерацією, статистикою показів і переходів та підняттям вакансій у пошуку.
- **Монетизація.** Перемикач платних послуг і ціни в адмінці. Поки вимкнено, усе безкоштовно.
- **Модерація.** Черга вакансій, публікація й відхилення з причиною, позначка «перевірений роботодавець». Модерувати власні вакансії не можна.
- **Адмін-панель.** Огляд, користувачі (пошук за телефоном чи email, блокування), ролі, журнал дій, 6 тем (застосування одним кліком), налаштування пошти.
- **Оновлення з адмінки.** Перевірка нових версій на GitHub, список змін, оновлення одним натисканням, автоматична резервна копія файлів і бази, відкат на попередню версію. Лише для головного і старшого адміністратора.
- **Публічна статистика.** Нові вакансії за сьогодні, кількість роботодавців, відвідувачі за сьогодні й за місяць (анонімно).
- **Права доступу.** 9 системних ролей, критичні права видаються окремо, власник може бути лише один (обмеження в базі).

## Безпека

- Паролі: Argon2id (або bcrypt, якщо хостинг не підтримує Argon2).
- Телефони й email зашифровані AES-256-GCM. Пошук іде за HMAC, без розшифрування.
- Захист від CSRF, httpOnly-сесії, обмеження спроб входу та запитів коду.
- Коди підтвердження зберігаються лише як HMAC, діють 10 хвилин, згорають після 5 помилок.
- Журнал дій лише на дописування (тригери MySQL, де хостинг дозволяє).
- Службові папки закриті `.htaccess`, а конфігурація — PHP-файл, тож через браузер його не прочитати.

## Структура

```
index.php              єдина точка входу
.htaccess              маршрути й захист папок
app/Core/              ядро: маршрутизатор, БД, сесії, безпека, інсталятор, теми, пошта
app/Controllers/       сторінки сайту, кабінет, адмінка
app/Views/             шаблони
app/Permissions.php    каталог прав і ролей
database/migrations/   SQL-міграції ({p} = префікс таблиць)
database/seed/         6 тем оформлення
CHANGELOG.md           список змін по версіях (показується в адмінці)
assets/                стилі
config/                файл конфігурації (створює інсталятор)
app/Fonts/              шрифт DejaVu Sans для PDF резюме
storage/               журнали, кеш, сесії, завантажені логотипи, банери й фото профілів (storage/uploads)
```

## Попередня версія

Версія на Node.js + PostgreSQL збережена в гілці `node-version`.
